# За новую индустриализацию!

Статический согласовательный макет общественной программы.

## Локальный запуск

```bash
python3 -m http.server 4179
```

Откройте `http://127.0.0.1:4179`.

## Проверка

```bash
node tests/smoke.mjs
```

Форма, видеокнопки, социальные ссылки и кнопки ресурсов намеренно не подключены к внешним endpoint’ам. В макете они демонстрируют только визуал и сценарий интерфейса.
